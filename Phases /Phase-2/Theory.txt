🔵 What are Azure AI Services?
Azure AI Services are pre-trained APIs for perception and language tasks:
Category	What it does	Used for
Vision	Image analysis, OCR, faces, layout	invoices, photos, scanning
Language	NER, sentiment, summarization	CRM, tickets
Speech	STT / TTS / translation	call centers
Document Intelligence	Form extraction	invoices, receipts
Translator	Multilingual text	global apps
📌 Key difference vs Azure ML:
•	Azure AI Services = ready-to-use models
•	Azure ML = you train models

This lives inside Azure AI Services and is used when:
📸 Input = image / scanned document / photo / camera feed
🧾 Output = text, layout, objects, meaning
________________________________________
🧠 Two Families You MUST Separate:
Azure splits visual AI into:
________________________________________
🔵 A) Vision Models (General Images)
Used for:
• image captioning
• tags
• object detection
• background removal
• people detection
• OCR in photos
• handwriting
Think:
👉 photos
👉 street signs
👉 whiteboards
👉 screenshots
👉 product images
________________________________________
🟣 B) Document Intelligence (Structured Docs)
Used for:
• invoices
• receipts
• forms
• contracts
• tables
• line items
• totals
• key-value pairs
Think:
👉 PDFs
👉 scans
👉 enterprise paperwork
________________________________________
⚠️ EXAM RULE:
Photo / scene → Vision
Business document → Document Intelligence
________________________________________
🔍 What is OCR Exactly?
OCR = Optical Character Recognition
It converts:
🖼️ image → 🔤 text + layout + bounding boxes
________________________________________
High-Value OCR Examples
________________________________________
OCR outputs:
• detected text
• line structure
• coordinates
• reading order
• handwriting vs printed
• confidence scores
________________________________________
🧾 Vision OCR vs Document OCR
Feature	Vision OCR	Document Intelligence
Scene text	✅	⚠️ limited
Handwriting	✅	✅
Tables	❌	✅
Key-value pairs	❌	✅
Invoices	❌	✅
Receipts	❌	✅
Contracts	❌	✅
________________________________________
🎯 Enterprise Decision Tree
Ask these:
❓ Is it a business form?
→ Document Intelligence
❓ Is it a photo?
→ Vision OCR
❓ Need totals, vendor names, rows?
→ Document Intelligence
❓ Just want text from sign or board?
→ Vision OCR
________________________________________

• per page

NOT per token like GenAI.

🧩 Core Capabilities Explained
________________________________________
📍 1) Named Entity Recognition (NER)
Extracts real-world objects:
• person
• org
• location
• date
• money
• product
Example:
“Ahmed paid $400 in Doha.”
→ Person = Ahmed
→ Money = 400
→ Location = Doha
________________________________________
________________________________________
🔐 2) PII Detection
Finds sensitive data:
• phone numbers
• email
• credit cards
• national IDs
• IBAN
• addresses
Can:
✔️ detect
✔️ mask
✔️ redact
Used for:
🏦 compliance
📞 call-center logs
📄 documents before indexing
________________________________________
________________________________________
😊 3) Sentiment + Opinion Mining
Sentiment:
• positive
• neutral
• negative
Opinion mining links:
feature → sentiment
“The price is high but the service is good.”
→ price = negative
→ service = positive
Very exam-friendly.
________________________________________
________________________________________
🏷️ 4) Key Phrase Extraction
Pulls main topics:
• “refund delay”
• “login problem”
• “billing error”
Used for dashboards & clustering.
________________________________________
________________________________________
📚 5) Text Classification
Assign labels:
• complaint
• praise
• technical issue
• billing
Two types:
🔵 Multi-class
(one label only)
🟣 Multi-label
(many allowed)
________________________________________
________________________________________
✍️ 6) Custom NER
You define:
• invoice_id
• product_code
• contract_number
Train using labeled text.
________________________________________
________________________________________
📉 7) Summarization
Two styles:
• extractive → picks original sentences
• abstractive → rewrites
Azure Language mostly focuses on extractive.
________________________________________
________________________________________
🏥 Healthcare Text Analytics

• medications
• dosage
• symptoms
• ICD codes
HIPAA-friendly scenarios.

🎙️ Azure Speech Services — Theory
This is a big enterprise pillar.
Used for:
• Call centers
• Voice bots
• Transcription
• Meeting summaries
• Real-time translation
• IVR systems
________________________________________
🧠 What Is Speech Service?
It converts between:
Speech ⇄ Text ⇄ Speech
Plus:
• Speaker identification
• Language detection
• Translation
• Voice synthesis
________________________________________
📦 Core Capabilities
________________________________________
🔵 1) Speech-to-Text (STT)
Converts audio → text.
Supports:
• real-time streaming
• batch transcription
• multiple languages
• punctuation
• profanity filtering
Enterprise uses:
📞 call center logs
📼 meeting transcription
🎙️ voice assistants
________________________________________
🟢 2) Text-to-Speech (TTS)
Converts text → natural voice.
Supports:
• neural voices
• multiple languages
• emotional tone
• SSML control
Used for:
🤖 chatbots
📱 mobile apps
📢 IVR systems
________________________________________
🟣 3) Speech Translation
Real-time:
English speech → Arabic text
French speech → English speech
Used in:
🌍 live meetings
🎧 international support
________________________________________
🟡 4) Speaker Diarization
Separates speakers in audio:
Speaker 1
Speaker 2
Very important for:
📞 contact centers
⚖️ legal recordings
🧑‍⚕️ medical notes
________________________________________
🔴 5) Custom Speech
You can train:
• custom acoustic models
• custom vocabulary
• domain terminology
Example:
Medical system learns:
“angioplasty”
“myocardial infarction”
________________________________________
💸 Pricing Model
Speech pricing depends on:
• minutes of audio processed
• real-time vs batch
• neural voice generation time
NOT tokens.
NOT per document.
________________________________________
🔐 Security
Same Azure enterprise model:
• RBAC
• Managed identity
• Private endpoints
• Disable keys
• Log audio usage
________________________________________

   ↓
Azure OpenAI
   ↓
Text-to-Speech
   ↓
User

❌ Saying Speech pricing uses tokens

🧠 Rapid-Fire Check
Answer mentally:
1️⃣ Which service separates speakers? 
Speaker diarization

2️⃣ Which converts text into Arabic speech?
 Text-to-Speech (TTS)

3️⃣ Which pricing model applies?
 Based on:
•	Minutes of audio processed

4️⃣ Which feature helps detect who said what?
•	Speaker Diarization → separates speakers in one recording (Speaker 1, Speaker 2)
